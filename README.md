# Tema Elegido: Libros
El programa que realizamos es para gestionar los libros de una biblioteca, donde se registra el nombre del libro, su autor, en que estante esta guardado, su precio en caso de perdida y su disponibilidad.

Al ejecutar el programa, contara con 4 opciones:

- Agregar un libro al archivo.
- Listar lo que se encuentra en el archivo.
- Listar los libros de "Borges".
- Dividir los libros en dos archivos (disponibles y no disponibles).
- Terminar el programa.

Se crearán tres archivos, libros.txt, disponibles.txt y nodisponibles.txt. El archivo libros.txt está subido al repositorio para probar las funciones del programa.
